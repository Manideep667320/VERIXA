# HELP-GLOSSARY — Glossary

- **Evidence**: retrieved source material used to support an answer or action.
- **Confidence**: the retrieval/reasoning score used by policy gates; the default execution threshold is defined in the active policy.
- **Run ID**: identifier for one agent run and its audit record.
- **Policy version**: immutable version of the YAML rules used for a decision.
- **Approval required**: a human must decide before the action proceeds.
- **Escalate**: stop autonomous action and route the case for human handling.
- **Verification**: independent read-back confirming an action reached its intended state.
- **`prev_hash`**: hash of the preceding audit row; **`row_hash`**: SHA-256 digest for this canonical audit row.
