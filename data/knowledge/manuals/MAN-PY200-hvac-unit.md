## 1. Product Overview

The PY-200 Commercial HVAC Unit is a modular heating, ventilation, and air conditioning system designed for commercial buildings, offices, and retail spaces. It provides both heating and cooling with intelligent zone management.

### 1.1 Key Specifications

| Parameter | Value |
|-----------|-------|
| Model | PY-200 |
| Cooling Capacity | 35 kW |
| Heating Capacity | 30 kW |
| Operating Range | 18°C – 28°C (cooling), 18°C – 30°C (heating) |
| Power Supply | 220–240V, single-phase / 380–480V, 3-phase |
| Refrigerant | R-32 |
| Weight | 420 kg |
| Zones Supported | Up to 8 |
| Warranty | 36 months from installation date |

### 1.2 Model Variants

- **PY-200-C**: Cooling only
- **PY-200-HP**: Heat pump (heating + cooling)
- **PY-200-Z**: Zone control with individual thermostats

## 2. Installation Requirements

### 2.1 Indoor Unit
- Mount on a structural wall capable of supporting 50 kg.
- Minimum 150mm clearance above and below for airflow.
- Connect condensate drain to building drainage.

### 2.2 Outdoor Unit
- Level concrete pad, minimum 100mm above grade.
- 500mm clearance on all sides.
- Protected from direct flooding.

## 3. Error Codes

### 3.1 HVAC Errors (H-1xx Series)

| Code | Description | Cause | Action |
|------|-------------|-------|--------|
| H-101 | Compressor overload | High ambient + high demand | Reduce set point spread, check airflow |
| H-102 | Refrigerant pressure low | Leak or undercharge | Schedule certified technician |
| H-103 | Indoor fan motor fault | Bearing wear, electrical fault | Replace fan motor |
| H-104 | Zone valve stuck | Actuator failure | Replace zone valve actuator |
| H-105 | Communication bus error | Wiring fault between zones | Check inter-zone wiring |

### 3.2 Environmental Errors (H-2xx Series)

| Code | Description | Cause | Action |
|------|-------------|-------|--------|
| H-201 | CO2 level exceeds threshold | Ventilation inadequate | Increase fresh air intake |
| H-202 | Humidity out of range | Humidifier/dehumidifier fault | Service humidity control |

## 5. Troubleshooting Guide

### 5.1 No Heating Output
1. Verify mode is set to HEAT, not COOL.
2. Check outdoor unit defrost cycle (in cold weather).
3. Inspect reversing valve for proper operation.

### 5.2 Uneven Zone Temperatures
1. Check zone valve operation — look for H-104 errors.
2. Verify zone thermostat readings against reference thermometer.
3. Inspect ductwork for obstructions or leaks.
